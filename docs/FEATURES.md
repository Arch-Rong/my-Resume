# 功能说明

本文档描述 **My Resume** 的功能范围与迭代计划，对标 [Oh My CV](https://ohmycv.app/)。

---

## 产品定位

- **输入**：Markdown（可选 YAML Front Matter）+ 自定义 CSS
- **输出**：浏览器内预览 + 导出 PDF
- **存储**：本地优先，无后端、无账号

---

## 页面结构

### 1. 落地页 `/`

- 产品介绍与核心卖点
- 「创建简历」入口
- 强调：开源、本地存储、无追踪

### 2. 简历列表 `/resumes`

- 卡片网格展示所有简历
- 缩略图预览（渲染缩小版）
- 显示标题、创建时间、更新时间
- 操作：新建、打开、重命名、删除
- 批量：**导出备份** / **从备份导入**（二期）

### 3. 编辑器 `/editor/:id`

三栏布局（参考 oh-my-cv）：

| 区域 | 内容 |
|------|------|
| 左栏 | Markdown / CSS 双 Tab 代码编辑 |
| 中栏 | 实时简历预览（分页、纸张尺寸） |
| 右栏 | 工具栏：保存、重命名、导出 PDF/Markdown、导入、纸张、主题色、字体、边距等 |

## 功能明细

### 编辑与预览

- [ ] Markdown 语法高亮编辑
- [ ] CSS 自定义样式编辑（二期）
- [ ] 输入防抖后实时更新预览
- [ ] `Ctrl/Cmd + S` 手动保存提示
- [ ] 支持 HTML 注释作为书写说明（不渲染到简历）

### 简历内容能力

- [ ] 标准 Markdown：标题、列表、链接、表格、引用
- [ ] GFM：任务列表、删除线等
- [ ] Front Matter：姓名、职位、联系方式（含图标字段，二期）
- [ ] Iconify 图标语法（二期）
- [ ] KaTeX 数学公式（二期）
- [ ] LaTeX 风格命令：行距 `\\[10px]`、换页 `\newpage`（二期，需 markdown-it 或自研 remark 插件）
- [ ] 交叉引用（学术 CV，二期）

### 排版与主题

- [ ] 纸张：A4、US Letter
- [ ] 页边距可调
- [ ] 主题色（影响标题、链接等强调色）
- [ ] 行高、段间距（二期）
- [ ] Google Fonts 字体选择（二期）
- [ ] 自动分页，避免标题孤行（二期）
- [ ] 大小写自动纠正（二期）

### 文档管理

- [ ] 新建默认模板简历
- [ ] 多份简历并存
- [ ] 重命名
- [ ] 删除（需确认）
- [ ] 自动保存（建议 500ms debounce）
- [ ] 导出单份 `.md`
- [ ] 导入 `.md` 覆盖或新建

### 导出

- [ ] 导出 PDF（浏览器打印流程）
- [ ] 打印样式与预览一致（共用 CSS 变量）
- [ ] 导出前可选纸张与边距

### 应用体验

- [ ] 深色 / 浅色 UI 主题
- [ ] 响应式布局（移动端可简化，编辑以桌面为主）
- [ ] 中英界面（i18n，可选，三期）
- [ ] PWA 离线（三期）

### 隐私与安全

- [ ] 数据仅存浏览器本地
- [ ] 无用户追踪、无广告
- [ ] 定期提醒用户通过「导出备份」自行备份（oh-my-cv 亦强调此点）

---

## 与 oh-my-cv 的差异（有意为之）

| 项目 | oh-my-cv | My Resume |
|------|----------|-----------|
| 前端框架 | Vue / Nuxt | React / Vite |
| 编辑器 | Monaco | CodeMirror 6 |
| 渲染 | markdown-it 生态 | MVP 用 react-markdown，进阶再评估 markdown-it |
| 部署 | GitHub Pages | 待定（Vercel / GitHub Pages 均可） |

功能上力求 **体验对齐**，实现栈允许不同，以降低仿写成本并便于个人维护。

---

## 验收标准（MVP）

1. 可创建多份简历并在列表中切换
2. 编辑 Markdown 后 1 秒内预览更新
3. 刷新页面后内容不丢失
4. 导出的 PDF 与预览版面基本一致（A4）
5. 可导入导出 `.md` 文件
