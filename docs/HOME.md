# 首页功能设计

参考 [Oh My CV](https://ohmycv.app/) 落地页，路径 `/`。

---

## 页面目标

1. **30 秒内**让用户理解产品：用 Markdown 写简历，本地私密
2. 提供唯一主操作：**创建简历**
3. 次要入口：**我的简历**（已有文档时）

---

## 功能清单

### Header

| 元素 | 行为 | 阶段 |
|------|------|------|
| Logo / 产品名 | 点击回到 `/` | MVP |
| 我的简历 | 跳转 `/resumes` | MVP |
| 主题切换 | 明 / 暗 / 跟随系统 | MVP |
| GitHub | 外链仓库（新标签打开） | MVP |
| 语言切换 | 中 / 英 i18n | 三期 |

### Hero

| 元素 | 行为 | 阶段 |
|------|------|------|
| 主标题 | 静态文案，关键词「resumes」高亮 | MVP |
| 副标题 | 产品价值一句话 | MVP |
| **Create My Resume** | 见下方「主 CTA 逻辑」 | MVP |

### 主 CTA 逻辑（Create My Resume）

```text
点击「Create My Resume」
  → 跳转 /resumes
  → 若本地无简历：自动创建一份默认模板并进入 /editor/:id
  → 若已有简历：进入列表页，用户自选或点「+」新建
```

MVP 可先简化为：**直接跳转 `/resumes`**，列表页负责新建。

### 特性双栏

纯展示，无交互。文案对齐 oh-my-cv 两大卖点：

- **Simple and Powerful**：编辑、预览、导出、定制能力
- **Privacy First**：本地、无账号、无追踪

### Footer

MVP 可极简：版权 + 开源协议说明，或省略（oh-my-cv 首页几乎无 Footer）。

## 交互与状态

| 场景 | 处理 |
|------|------|
| 首次访问 | 展示完整 Hero + 双栏特性 |
| 再次访问（本地已有简历） | 可选：Hero 副 CTA「查看我的简历」→ `/resumes` |
| 暗色模式 | 默认跟随系统；偏好存 `localStorage.theme` |
| 窄屏 | Hero 居中；双栏改单列堆叠 |

## 非目标（首页不做）

- 登录 / 注册
- 在线演示编辑器
- 模板市场展示
- 数据统计、埋点
